# DriftCue · 觉察此刻

个人本地 Chrome 扩展。在选定网站的网页可视区域，周期性浮现一张随机位置、随机文案的提醒卡片。卡片整体点击穿透，数据仅保存在本机，无服务器、账号、统计、广告或远程脚本。

## 本地安装

需要 Chrome 120 或更新版本。直接使用源码无需 Node、npm 或构建：

1. 在 Chrome 手动打开 `chrome://extensions`，开启开发者模式。
2. 点击“加载已解压的扩展程序”，选择本项目的 **extension** 目录（内含 `manifest.json`）。
3. 在工具栏的扩展菜单中固定 DriftCue，点击图标 → 打开设置。
4. 默认只有 bilibili 规则。点击该规则的“授权并启用”，接受指定网站的访问许可，再点击“保存设置”。未授权时明确显示“权限不足”，不会自动开始。
5. 打开/刷新目标网页。默认首次等待 120 秒，卡片显示 4 秒，之后每 120 秒提醒一次。

可选打包：安装 Node 20+ 后运行 `npm run build`，可加载 `dist/DriftCue`；`dist/SHA256SUMS.txt` 提供文件校验和。无第三方 npm 依赖，不需要 `npm install`。

## 使用

- **弹窗**：全局开关、当前网站状态、本次暂停分钟数、立即恢复、关闭当前卡片、立即预览、打开设置。
- **设置页**：背景/文字颜色、背景透明度、间隔秒数、保持秒数、默认暂停分钟数、文案列表和网站列表。修改后点击保存。保存会清除旧卡片，普通提醒重新等待完整间隔；已有暂停截止时间保留。
- **文案**：1–100 条，每条 1–200 个 Unicode 字符，支持换行；仅显示纯文本。不可保存全空白文字，不可删除最后一条。
- **透明度**：0% 背景完全不透明，100% 背景完全透明；文字颜色不受影响。
- **动画**：卡片用约 180 毫秒淡入、220 毫秒淡出，包含在设置的保持时间内，不延长提醒周期。切页、暂停、关闭或进入全屏时立即清除。启用系统“减少动态效果”时直接显示与消失。
- **网站**：可输入域名或完整 HTTP/HTTPS 网址，路径不参与匹配，所有端口适用。默认包含子域名，可在添加时关闭。重复名称/域名和覆盖重叠规则不能保存。YouTube 与 X 快捷项需自行添加、授权、启用并保存，别名不会自动加入。
- **授权**是独立操作，网站规则修改则统一保存。删除/关闭规则不自动撤回已授予的 Chrome 权限；需要时可在 Chrome 的扩展详情中手动撤回。
- **暂停**仅影响当前规则的全部标签页，默认 10 分钟。提前恢复或到期恢复后重新等待完整间隔。重复暂停以最新操作时间计算截止时间。
- **关闭当前卡片**只关闭这一张，不暂停后续提醒，不改变下一次到期时间。卡片无按钮、不会抢焦点。
- **预览**：弹窗可用 Chrome 的 activeTab 临时访问当前支持网页；设置页选择已获访问许可的目标网页，预览会切换过去。预览使用当前未保存表单的有效外观/文字，不保存、不改变普通计时或暂停。全屏期间拒绝预览，退出不会补发。

## 计时和边界

每个网站规则一个计时器；多个标签页不加速。网站还有标签页打开就继续计时，切换应用/后台/最小化不暂停。后台或播放器全屏到期最多保留一次待显示提醒，返回前台或退出全屏后立即显示，下一周期从实际显示时刻起算。

仅焦点 Chrome 窗口的活动目标网页显示；切页、离开 Chrome、禁用、撤权或暂停会清除相应卡片。关闭网站最后一个标签页清除计时。Chrome 完全退出、扩展重载/更新后普通计时重新开始，配置与未到期暂停保留。Worker 空闲挂起不会重置普通计时。

支持普通 HTTP/HTTPS 顶层网页；浏览器内置页、Chrome Web Store、PDF、其他扩展页、本地文件、无痕和画中画不纳入首版。浏览器 Fullscreen API 全屏暂停显示；F11 和网站的“网页全屏”布局按普通网页处理。设备休眠/网页冻结/高负载时可能延迟，不唤醒设备、不批量补发。

## 开发与验证

```powershell
npm test          # 纯业务、Chrome API 集成模拟、内容脚本行为测试
npm run check     # JS 语法、CSP、资源、无远程请求/HTML 注入检查
npm run build     # 复制可加载扩展及生成 SHA-256 清单
npm run dev       # 本机 4173 端口的交互验收页；Ctrl+C 停止
```

验收页：`http://localhost:4173/` 和 `http://127.0.0.1:4173/`。将二者分别作为规则添加授权，即可验证两个独立站点，不接触真实账号。测试页记录卡片出现/消失时间、边界、焦点、点击、全屏等非敏感测试事件至 `artifacts/browser-events.jsonl`。扩展本身不发送任何网络请求。测试页和服务器不包含在扩展目录中。

动画渲染验收页：`http://localhost:4173/animation`，运行真实 `content.js`（仅 Chrome 消息接口模拟）。点击“运行渲染验收”可检查 1/4/60 秒下的淡化曲线、总时长、样式、点击穿透与立即清除；也可直接显示一张 4 秒卡片查看效果。

更新后在扩展管理页重新加载，并刷新所有目标网页，避免旧内容脚本继续运行。不要删除扩展再安装，否则 Chrome 会清除扩展数据。

实现设计见 [docs/design.md](docs/design.md)，配置示例见 [docs/config.example.json](docs/config.example.json)。实际验收状态、未完成项见 [PROGRESS.md](PROGRESS.md)，不能用模拟测试替代真实浏览器验证。
